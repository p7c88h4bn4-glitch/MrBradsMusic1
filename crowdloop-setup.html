4Set up Supabase

This is the part that holds your recordings and enforces the rules. Four short steps.

⏰

Read this before your first show

A free Supabase project goes to sleep after 7 days with nothing happening, and can be closed for good after 90 days asleep. Waking it is one click from the dashboard — but it will not wake by itself when someone opens your recording page.

If it has been more than a week since your last show, open your Supabase dashboard the day before and check the project is awake. This is the most common cause of a page that will not connect.

Run first

Build everything

-- ============================================================================
-- CrowdLoop Phase 2 — schema, security, storage
-- Run this once in the Supabase SQL Editor (Dashboard -> SQL Editor -> New query).
-- Safe to re-run: everything is idempotent.
-- ============================================================================

-- ---------------------------------------------------------------------------
-- SECURITY MODEL
--
-- Audience members are never authenticated. They hold only the publishable
-- key, which is public by design, so the database itself has to be the
-- boundary. Three rules follow from that:
--
--   1. anon has NO direct read on sessions. It can only call one function,
--      get_open_session(code), which returns a single open session and only
--      the fields a recording page needs. Without this, holding the
--      publishable key would let anyone enumerate every open session.
--
--   2. anon can INSERT a submission but never SELECT, UPDATE or DELETE one.
--      An audience member cannot read back their own upload, cannot see
--      anyone else's, and cannot approve anything. Moderation is the
--      performer's alone.
--
--   3. anon can write into storage but never read. Audio comes back out only
--      through a signed URL minted for the authenticated owner.
--
-- The insert policies need to check "is this session open?", but anon cannot
-- read sessions. That is what session_is_open() is for: SECURITY DEFINER, so
-- the check runs with the owner's rights while the caller stays blind.
-- ---------------------------------------------------------------------------

-- ============================================================================
-- TABLES
-- ============================================================================

create table if not exists public.sessions (
    id                      uuid primary key default gen_random_uuid(),
    owner_id                uuid not null references auth.users(id) on delete cascade,
    title                   text not null,
    prompt                  text not null default '',
    status                  text not null default 'draft',
    -- Short code carried by the QR image. Also typeable by hand, which
    -- matters when a phone camera will not focus in a dark room.
    public_code             text not null unique,
    max_duration_seconds    integer not null default 3,
    -- Abuse ceiling per session. Cheap, and it bounds a flood without
    -- needing per-IP tracking.
    max_submissions         integer not null default 300,
    created_at              timestamptz not null default now(),
    closes_at               timestamptz,

    constraint sessions_status_valid
        check (status in ('draft', 'open', 'closed')),
    constraint sessions_duration_sane
        check (max_duration_seconds between 1 and 10),
    constraint sessions_code_shape
        check (public_code ~ '^[A-Z0-9]{4,12}$')
);

create table if not exists public.submissions (
    id              uuid primary key default gen_random_uuid(),
    session_id      uuid not null references public.sessions(id) on delete cascade,
    status          text not null default 'pending',
    label           text not null default '',
    duration        real not null default 0,
    -- Path inside the private 'submissions' bucket: <session_id>/<id>.wav
    storage_path    text,
    mime_type       text,
    file_size       integer,
    -- 0..15, or null when approved but not yet placed on a pad.
    assigned_pad    integer,
    created_at      timestamptz not null default now(),

    constraint submissions_status_valid
        check (status in ('pending', 'approved', 'rejected')),
    constraint submissions_pad_range
        check (assigned_pad is null or assigned_pad between 0 and 15),
    constraint submissions_duration_sane
        check (duration >= 0 and duration <= 10)
);

-- One sound per pad per session.
create unique index if not exists submissions_one_per_pad
    on public.submissions (session_id, assigned_pad)
    where assigned_pad is not null;

create index if not exists submissions_by_session
    on public.submissions (session_id, created_at desc);

create index if not exists sessions_by_owner
    on public.sessions (owner_id, created_at desc);

-- ============================================================================
-- HELPERS
-- ============================================================================

-- Ambiguity-free alphabet: no O/0, no I/1, no S/5. A code read aloud from a
-- stage, or squinted at from the back of a room, should not need a retry.
create or replace function public.generate_session_code()
returns text
language plpgsql
as $$
declare
    alphabet constant text := 'ABCDEFGHJKLMNPQRTUVWXYZ23456789';
    candidate text;
    attempt integer := 0;
begin
    loop
        candidate := '';
        for i in 1..6 loop
            candidate := candidate ||
                substr(alphabet, 1 + floor(random() * length(alphabet))::int, 1);
        end loop;

        exit when not exists (
            select 1 from public.sessions where public_code = candidate
        );

        attempt := attempt + 1;
        if attempt > 50 then
            raise exception 'Could not allocate a unique session code';
        end if;
    end loop;

    return candidate;
end;
$$;

-- SECURITY DEFINER so RLS policies can ask this question on behalf of a
-- caller that has no read access to sessions at all.
create or replace function public.session_is_open(target uuid)
returns boolean
language sql
security definer
set search_path = public
stable
as $$
    select exists (
        select 1
        from public.sessions
        where id = target
          and status = 'open'
          and (closes_at is null or closes_at > now())
    );
$$;

-- The only window anon has onto sessions. Takes a code, returns at most one
-- row, and never exposes owner_id or anything else internal.
create or replace function public.get_open_session(code text)
returns table (
    id uuid,
    title text,
    prompt text,
    max_duration_seconds integer
)
language sql
security definer
set search_path = public
stable
as $$
    select s.id, s.title, s.prompt, s.max_duration_seconds
    from public.sessions s
    where s.public_code = upper(trim(code))
      and s.status = 'open'
      and (s.closes_at is null or s.closes_at > now())
    limit 1;
$$;

-- Enforces the per-session ceiling at write time.
create or replace function public.enforce_submission_cap()
returns trigger
language plpgsql
security definer
set search_path = public
as $$
declare
    ceiling integer;
    current_total integer;
begin
    select max_submissions into ceiling
    from public.sessions
    where id = new.session_id;

    select count(*) into current_total
    from public.submissions
    where session_id = new.session_id;

    if current_total >= coalesce(ceiling, 300) then
        raise exception 'This session has reached its submission limit'
            using errcode = 'check_violation';
    end if;

    return new;
end;
$$;

drop trigger if exists submissions_cap on public.submissions;
create trigger submissions_cap
    before insert on public.submissions
    for each row execute function public.enforce_submission_cap();

-- ============================================================================
-- ROW LEVEL SECURITY
-- ============================================================================

alter table public.sessions    enable row level security;
alter table public.submissions enable row level security;

-- --- sessions: owner only, in every direction ---

drop policy if exists "owner reads own sessions" on public.sessions;
create policy "owner reads own sessions"
    on public.sessions for select
    to authenticated
    using (owner_id = auth.uid());

drop policy if exists "owner creates own sessions" on public.sessions;
create policy "owner creates own sessions"
    on public.sessions for insert
    to authenticated
    with check (owner_id = auth.uid());

drop policy if exists "owner updates own sessions" on public.sessions;
create policy "owner updates own sessions"
    on public.sessions for update
    to authenticated
    using (owner_id = auth.uid())
    with check (owner_id = auth.uid());

drop policy if exists "owner deletes own sessions" on public.sessions;
create policy "owner deletes own sessions"
    on public.sessions for delete
    to authenticated
    using (owner_id = auth.uid());

-- Note: no anon policy on sessions at all. get_open_session() is the door.

-- --- submissions: anon writes, owner reads and moderates ---

drop policy if exists "anon submits to open sessions" on public.submissions;
create policy "anon submits to open sessions"
    on public.submissions for insert
    to anon
    with check (
        public.session_is_open(session_id)
        -- An audience member cannot pre-approve their own sound or park it
        -- straight onto a pad.
        and status = 'pending'
        and assigned_pad is null
    );

-- A signed-in performer submitting into their own session, e.g. testing.
drop policy if exists "owner submits to own sessions" on public.submissions;
create policy "owner submits to own sessions"
    on public.submissions for insert
    to authenticated
    with check (
        exists (
            select 1 from public.sessions s
            where s.id = session_id and s.owner_id = auth.uid()
        )
    );

drop policy if exists "owner reads own submissions" on public.submissions;
create policy "owner reads own submissions"
    on public.submissions for select
    to authenticated
    using (
        exists (
            select 1 from public.sessions s
            where s.id = session_id and s.owner_id = auth.uid()
        )
    );

drop policy if exists "owner moderates own submissions" on public.submissions;
create policy "owner moderates own submissions"
    on public.submissions for update
    to authenticated
    using (
        exists (
            select 1 from public.sessions s
            where s.id = session_id and s.owner_id = auth.uid()
        )
    )
    with check (
        exists (
            select 1 from public.sessions s
            where s.id = session_id and s.owner_id = auth.uid()
        )
    );

drop policy if exists "owner deletes own submissions" on public.submissions;
create policy "owner deletes own submissions"
    on public.submissions for delete
    to authenticated
    using (
        exists (
            select 1 from public.sessions s
            where s.id = session_id and s.owner_id = auth.uid()
        )
    );

-- ============================================================================
-- STORAGE
-- ============================================================================

-- Private bucket. 'public' false means no URL works without a signature.
insert into storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
values (
    'submissions',
    'submissions',
    false,
    2097152,                        -- 2 MB ceiling; a 3 s mono WAV is ~290 KB
    array['audio/wav', 'audio/x-wav', 'audio/wave']
)
on conflict (id) do update
set public = false,
    file_size_limit = 2097152,
    allowed_mime_types = array['audio/wav', 'audio/x-wav', 'audio/wave'];

drop policy if exists "anon uploads to open sessions" on storage.objects;
create policy "anon uploads to open sessions"
    on storage.objects for insert
    to anon
    with check (
        bucket_id = 'submissions'
        -- First path segment is the session id: <session_id>/<submission_id>.wav
        and public.session_is_open(((storage.foldername(name))[1])::uuid)
    );

drop policy if exists "owner reads own session audio" on storage.objects;
create policy "owner reads own session audio"
    on storage.objects for select
    to authenticated
    using (
        bucket_id = 'submissions'
        and exists (
            select 1 from public.sessions s
            where s.id = ((storage.foldername(name))[1])::uuid
              and s.owner_id = auth.uid()
        )
    );

drop policy if exists "owner deletes own session audio" on storage.objects;
create policy "owner deletes own session audio"
    on storage.objects for delete
    to authenticated
    using (
        bucket_id = 'submissions'
        and exists (
            select 1 from public.sessions s
            where s.id = ((storage.foldername(name))[1])::uuid
              and s.owner_id = auth.uid()
        )
    );

-- ============================================================================
-- GRANTS
-- ============================================================================

grant usage on schema public to anon, authenticated;

grant select, insert, update, delete on public.sessions    to authenticated;
grant select, insert, update, delete on public.submissions to authenticated;
grant insert                          on public.submissions to anon;

grant execute on function public.get_open_session(text)  to anon, authenticated;
grant execute on function public.session_is_open(uuid)   to anon, authenticated;
grant execute on function public.generate_session_code() to authenticated;

-- anon deliberately gets nothing on sessions.
revoke all on public.sessions from anon;

Makes your tables, the private audio folder, and the rules that keep recordings yours. A warning may pop up — always choose the green Run and enable RLS, never Run without RLS.

Run third

Check it worked

-- ============================================================================
-- CrowdLoop Phase 2 — verification
-- Run AFTER 01_schema.sql. Each block should print PASS.
-- ============================================================================

-- 1. Tables exist with RLS on
select
    case when count(*) = 2 then 'PASS: both tables exist with RLS enabled'
         else 'FAIL: expected 2 RLS-enabled tables, found ' || count(*)
    end as result
from pg_tables
where schemaname = 'public'
  and tablename in ('sessions', 'submissions')
  and rowsecurity = true;

-- 2. anon has no read path into sessions
select
    case when count(*) = 0 then 'PASS: anon has no policy on sessions'
         else 'FAIL: anon can reach sessions directly through ' || count(*) || ' policy'
    end as result
from pg_policies
where schemaname = 'public'
  and tablename = 'sessions'
  and 'anon' = any(roles);

-- 3. anon can insert submissions but nothing else
select
    case when count(*) filter (where cmd = 'INSERT') = 1
          and count(*) filter (where cmd <> 'INSERT') = 0
         then 'PASS: anon on submissions is insert-only'
         else 'FAIL: anon has unexpected access to submissions'
    end as result
from pg_policies
where schemaname = 'public'
  and tablename = 'submissions'
  and 'anon' = any(roles);

-- 4. Bucket is private
select
    case when not public then 'PASS: submissions bucket is private'
         else 'FAIL: submissions bucket is PUBLIC — audio is world-readable'
    end as result
from storage.buckets
where id = 'submissions';

-- 5. anon can write to storage but not read it
select
    case when count(*) filter (where cmd = 'INSERT') >= 1
          and count(*) filter (where cmd = 'SELECT') = 0
         then 'PASS: anon can upload but not download'
         else 'FAIL: check anon storage policies'
    end as result
from pg_policies
where schemaname = 'storage'
  and tablename = 'objects'
  and 'anon' = any(roles);

-- 6. Helper functions are SECURITY DEFINER
select
    case when count(*) = 2 then 'PASS: helper functions are SECURITY DEFINER'
         else 'FAIL: expected 2 definer functions, found ' || count(*)
    end as result
from pg_proc p
join pg_namespace n on n.oid = p.pronamespace
where n.nspname = 'public'
  and p.proname in ('get_open_session', 'session_is_open')
  and p.prosecdef = true;

-- 7. Code generator produces a valid code
select
    case when public.generate_session_code() ~ '^[A-Z0-9]{6}$'
         then 'PASS: session codes generate correctly'
         else 'FAIL: generate_session_code() returned an unexpected shape'
    end as result;

Marks every rule pass or fail. Every row must say PASS. A FAIL means your recordings are not protected — run the first block again and re-check.

Proving the rules hold

Worth doing once. Each of these should fail to give you anything.

  • A closed session refuses uploads. Set your session's status to closed, reload the page, try to send. It should be refused. Set it back to open.
  • Your key does not leak your sessions. Open YOUR-URL/rest/v1/sessions?apikey=YOUR-KEY in a browser. You want an empty [] or an error — not a list.
  • Audio is not world-readable. Copy an uploaded .wav URL from Storage and open it in a private window. It must be denied.

If you can see your sessions or play that file, run the first block in step 4.2 again before using this at an event.

8At the show

  • Keep exactly one session open. Two open sessions means sounds land in one while you watch the other stay empty. Nothing errors, which is what makes it the most common self-inflicted problem.
  • The code and the QR do the same thing. The QR skips the code screen; the six characters can always be typed, which matters when a camera will not focus in a dark room.
  • Codes avoid lookalikes. No O/0, I/1 or S/5, so a code survives being read aloud from a stage.
  • Closing a session is instant and affects new uploads only. Sounds already on your pads keep working.
  • Levels are evened out automatically, so a quiet phone at the back still comes through the PA.
  • Every phone sounds the same by the time it reaches your pads.
  • Stuck? Add &debug=1 to the page address to see where it is failing.

10When something breaks

The page spins forever, or says it cannot connect

In order of likelihood:

  1. Your Supabase project is asleep. Open the dashboard and resume it. By far the most common cause after a gap between shows.
  2. The details in the page are wrong. Build it again in step 5 and re-deploy.
  3. The code in step 4.2 was never run, or only partly. Run the first block again.
  4. You are looking at a cached copy. Try a private window.

Add &debug=1 to the address and the page will name the actual failure instead of a polite one.

"No open session with that code"

The connection is fine — the lookup found nothing. Either the code is wrong or that session is closed.

select public_code, status, title from public.sessions order by created_at desc;
The page looks old after I deployed a new one

Netlify and phone browsers both cache hard, and you can spend a long time debugging a file that is not the one you deployed. A private window bypasses the cache and is quickest for a spot check. On iPhone: Settings → Safari → Clear History and Website Data.

Playback works on my computer but not on my phone

Almost always the phone's audio routing. Once a page has used the microphone, iOS sends sound to the earpiece and the ring/silent switch mutes it, with no error at all. The page already handles this — so if you have edited the page yourself and playback has gone silent, that is the first thing to check.

A sound uploaded but never showed up in the app

The confirmation screen only appears once the upload has succeeded, so it almost certainly exists. Check which session it landed in — if it is not the one the app has selected, you had two sessions open.

select
    sub.created_at,
    s.public_code as landed_in_code,

  function uuid() {
    if (window.crypto && typeof window.crypto.randomUUID === "function") {
      return window.crypto.randomUUID();
    }
    // Fallback for older Safari. Still uses a CSPRNG.
    var bytes = new Uint8Array(16);
    (window.crypto || window.msCrypto).getRandomValues(bytes);
    bytes[6] = (bytes[6] & 0x0f) | 0x40;
    bytes[8] = (bytes[8] & 0x3f) | 0x80;
    var hex = [];
    for (var i = 0; i < 16; i++) {
      hex.push((bytes[i] + 0x100).toString(16).slice(1));
    }
    return hex.slice(0, 4).join("") + "-" +
           hex.slice(4, 6).join("") + "-" +
           hex.slice(6, 8).join("") + "-" +
           hex.slice(8, 10).join("") + "-" +
           hex.slice(10, 16).join("");
  }

  function AudioContextClass() {
    return window.AudioContext || window.webkitAudioContext;
  }

  // iOS decides where audio comes out based on the page's audio session. Once
  // getUserMedia runs, the session goes into record mode and output routes to
  // the earpiece receiver rather than the speaker — and the ring/silent switch
  // mutes it. Both are inaudible with the phone in your hand, and neither shows
  // up as an error: the context still reports "running" and playback still
  // completes normally.
  //
  // Declaring "playback" before making sound forces speaker output and opts out
  // of the silent switch. Safari 16.4+ only; harmless where it is missing.
  function setAudioSession(type) {
    try {
      if (navigator.audioSession) {
        navigator.audioSession.type = type;
        return type;
      }
    } catch (e) { /* not supported */ }
    return null;
  }

  function describeSession() {
    if (!navigator.audioSession) { return "audioSession unsupported"; }
    try {
      return "audioSession=" + navigator.audioSession.type;
    } catch (e) {
      return "audioSession unreadable";
    }
  }

  // Must be called synchronously from inside a click handler. iOS starts every
  // AudioContext suspended and will only resume one in response to a real
  // gesture, so deferring this into a callback silently breaks playback.
  function unlockAudio() {
    try {
      if (!sharedCtx) {
        var Ctx = AudioContextClass();
        if (!Ctx) { return null; }
        sharedCtx = new Ctx();
      }
      if (sharedCtx.state === "suspended" && typeof sharedCtx.resume === "function") {
        sharedCtx.resume();
      }
      return sharedCtx;
    } catch (e) {
      return null;
    }
  }

  // fetch() has no default timeout: a request that never settles leaves the
  // page on its spinner indefinitely. Twelve seconds is long enough for a
  // slow phone on bad wifi and short enough to tell someone something.
  function fetchWithTimeout(url, options, seconds) {
    var limit = (seconds || 12) * 1000;

    if (typeof AbortController === "undefined") {
      return fetch(url, options);
    }

    var controller = new AbortController();
    var timer = setTimeout(function () { controller.abort(); }, limit);

    options = options || {};
    options.signal = controller.signal;

    return fetch(url, options).then(function (response) {
      clearTimeout(timer);
      return response;
    }).catch(function (error) {
      clearTimeout(timer);
      if (error && error.name === "AbortError") {
        throw new Error("TIMEOUT after " + (limit / 1000) + "s — the request " +
                        "was sent but nothing came back.");
      }
      throw error;
    });
  }

  function supabaseHeaders(extra) {
    var headers = {
      "apikey": SUPABASE_KEY,
      "Authorization": "Bearer " + SUPABASE_KEY
    };
    if (extra) {
      Object.keys(extra).forEach(function (k) { headers[k] = extra[k]; });
    }
    return headers;
  }

  // The only session lookup anon is allowed. Everything else about sessions
  // is invisible to this page by design.
  function lookupSession(code) {
    return fetchWithTimeout(SUPABASE_URL + "/rest/v1/rpc/get_open_session", {
      method: "POST",
      headers: supabaseHeaders({ "Content-Type": "application/json" }),
      body: JSON.stringify({ code: code })
    }, 12).then(function (response) {
      if (!response.ok) {
        return response.text().then(function (body) {
          throw new Error("Lookup failed (" + response.status + "): " + body);
        });
      }
      return response.json();
    }).then(function (rows) {
      if (!rows || rows.length === 0) { return null; }
      return rows[0];
    });
  }

  // Audio is uploaded first, then the row is written. A row that exists
  // therefore always has audio behind it; a failed send leaves at most an
  // unreferenced file, which is harmless.
  // Free text from an anonymous stranger, so it is bounded and flattened here
  // as well as by maxlength: newlines and control characters would otherwise
  // break the layout of the moderation queue.
  function cleanLabel(raw) {
    if (!raw) { return ""; }
    return String(raw)
      .replace(/[\u0000-\u001F\u007F]/g, " ")
      .replace(/\s+/g, " ")
      .trim()
      .slice(0, 40);
  }

  function createSubmission(submissionId, sessionId, storagePath, seconds, bytes, label) {
    return fetchWithTimeout(SUPABASE_URL + "/rest/v1/submissions", {
      method: "POST",
      headers: supabaseHeaders({
        "Content-Type": "application/json",
        // anon has no SELECT on submissions, so asking for the row back
        // would fail the request. Minimal is correct here.
        "Prefer": "return=minimal"
      }),
      body: JSON.stringify({
        id: submissionId,
        session_id: sessionId,
        status: "pending",
        label: cleanLabel(label),
        duration: seconds,
        storage_path: storagePath,
        mime_type: "audio/wav",
        file_size: bytes
      })
    }, 12).then(function (response) {
      if (!response.ok) {
        return response.text().then(function (body) {
          throw new Error("Save failed (" + response.status + "): " + body);
        });
      }
      return true;
    });
  }

  // -------------------------------------------------------------------------
  // Audio conversion
  //
  // MediaRecorder gives WebM/Opus on Android and MP4/AAC on iOS. AVFoundation
  // in the app cannot decode WebM at all, so rather than transcode on a
  // server we decode here and emit 16-bit mono WAV at a fixed sample rate.
  // One format reaches the sampler, whatever the phone produced.
  // -------------------------------------------------------------------------

  function decodeToBuffer(blob) {
    return blob.arrayBuffer().then(function (data) {
      var Ctx = AudioContextClass();
      var ctx = new Ctx();
      return new Promise(function (resolve, reject) {
        // Callback form: older Safari does not return a promise here.
        var maybe = ctx.decodeAudioData(data, function (buffer) {
          resolve({ buffer: buffer, ctx: ctx });
        }, function (err) {
          reject(err || new Error("Could not decode the recording"));
        });
        if (maybe && typeof maybe.then === "function") {
          maybe.then(function (buffer) {
            resolve({ buffer: buffer, ctx: ctx });
          }).catch(reject);
        }
      });
    });
  }

  function resampleToMono(buffer, maxSeconds) {
    var seconds = Math.min(buffer.duration, maxSeconds);
    var frames = Math.max(1, Math.ceil(seconds * TARGET_SAMPLE_RATE));

    var Offline = window.OfflineAudioContext || window.webkitOfflineAudioContext;
    var offline = new Offline(1, frames, TARGET_SAMPLE_RATE);

    var source = offline.createBufferSource();
    source.buffer = buffer;

    // Trim first, then let the offline context do the rate conversion.
    source.connect(offline.destination);
    source.start(0, 0, seconds);

    var rendered = offline.startRendering();
    if (rendered && typeof rendered.then === "function") {
      return rendered;
    }
    return new Promise(function (resolve) {
      offline.oncomplete = function (event) { resolve(event.renderedBuffer); };
    });
  }

  function encodeWav(audioBuffer) {
    var samples = audioBuffer.getChannelData(0);
    var frameCount = samples.length;
    var bytesPerSample = 2;
    var dataBytes = frameCount * bytesPerSample;
    var buffer = new ArrayBuffer(44 + dataBytes);
    var view = new DataView(buffer);

    function writeString(offset, text) {
      for (var i = 0; i < text.length; i++) {
        view.setUint8(offset + i, text.charCodeAt(i));
      }
    }

    writeString(0, "RIFF");
    view.setUint32(4, 36 + dataBytes, true);
    writeString(8, "WAVE");
    writeString(12, "fmt ");
    view.setUint32(16, 16, true);                       // PCM chunk size
    view.setUint16(20, 1, true);                        // format = PCM
    view.setUint16(22, 1, true);                        // channels = mono
    view.setUint32(24, TARGET_SAMPLE_RATE, true);
    view.setUint32(28, TARGET_SAMPLE_RATE * bytesPerSample, true);
    view.setUint16(32, bytesPerSample, true);           // block align
    view.setUint16(34, 16, true);                       // bits per sample
    writeString(36, "data");
    view.setUint32(40, dataBytes, true);

    // Find the loudest point so quiet recordings are not inaudible over a PA.
    // Capped so a near-silent take is not amplified into pure noise.
    var peak = 0;
    for (var p = 0; p < frameCount; p++) {
      var magnitude = samples[p] < 0 ? -samples[p] : samples[p];
      if (magnitude > peak) { peak = magnitude; }
    }
    var gain = 1;
    if (peak > 0.0001) {
      gain = Math.min(0.89 / peak, 8);
    }

    var offset = 44;
    for (var i = 0; i < frameCount; i++) {
      var value = samples[i] * gain;
      if (value > 1) { value = 1; } else if (value < -1) { value = -1; }
      view.setInt16(offset, Math.round(value * 32767), true);
      offset += 2;
    }

    return new Blob([buffer], { type: "audio/wav" });
  }

  function convertRecording(blob, maxSeconds) {
    var context = null;
    return decodeToBuffer(blob).then(function (result) {
      context = result.ctx;
      return resampleToMono(result.buffer, maxSeconds);
    }).then(function (rendered) {
      if (context && typeof context.close === "function") { context.close(); }
      return {
        wav: encodeWav(rendered),
        seconds: rendered.length / TARGET_SAMPLE_RATE
      };
    }).catch(function (error) {
      if (context && typeof context.close === "function") { context.close(); }
      throw error;
    });
  }

  function pickMimeType() {
    if (typeof MediaRecorder === "undefined" ||
        typeof MediaRecorder.isTypeSupported !== "function") {
      return "";
    }
    var candidates = [
      "audio/webm;codecs=opus",
      "audio/webm",
      "audio/mp4",
      "audio/aac",
      "audio/ogg;codecs=opus"
    ];
    for (var i = 0; i < candidates.length; i++) {
      if (MediaRecorder.isTypeSupported(candidates[i])) { return candidates[i]; }
    }
    return "";
  }

  function startLevelMeter(stream) {
    try {
      var ctx = unlockAudio();
      if (!ctx) { return; }
      meterSource = ctx.createMediaStreamSource(stream);
      analyser = ctx.createAnalyser();
      analyser.fftSize = 512;
      meterSource.connect(analyser);

      var data = new Uint8Array(analyser.frequencyBinCount);
      var fill = $("meter-fill");

      var draw = function () {
        analyser.getByteTimeDomainData(data);
        var peak = 0;
        for (var i = 0; i < data.length; i++) {
          var deviation = Math.abs(data[i] - 128);
          if (deviation > peak) { peak = deviation; }
        }
        fill.style.width = Math.min(100, (peak / 128) * 140) + "%";
        levelRaf = requestAnimationFrame(draw);
      };
      draw();
    } catch (e) {
      // A missing level meter is cosmetic; recording still works.
    }
  }

  function stopLevelMeter() {
    if (levelRaf) { cancelAnimationFrame(levelRaf); levelRaf = null; }
    if (meterSource) {
      try { meterSource.disconnect(); } catch (e) { /* already gone */ }
      meterSource = null;
    }
    if (analyser) {
      try { analyser.disconnect(); } catch (e) { /* already gone */ }
      analyser = null;
    }
    // sharedCtx is intentionally left open and unlocked for playback.
  }

  function clearTimers() {
    if (stopTimer) { clearTimeout(stopTimer); stopTimer = null; }
    if (tickTimer) { clearInterval(tickTimer); tickTimer = null; }
  }

  function releaseStream() {
    if (mediaStream) {
      mediaStream.getTracks().forEach(function (track) { track.stop(); });
      mediaStream = null;
    }
  }

  function startRecording() {
    if (!navigator.mediaDevices || !navigator.mediaDevices.getUserMedia) {
      setStatus("record-status",
        "This browser cannot record audio. Try Safari or Chrome.", "error");
      return;
    }

    setStatus("record-status", "");
    setAudioSession("play-and-record");

    var button = $("record-btn");
    button.disabled = true;

    navigator.mediaDevices.getUserMedia({
      audio: {
        echoCancellation: false,
        noiseSuppression: false,
        autoGainControl: true
      }
    }).then(function (stream) {
      mediaStream = stream;
      chunks = [];

      var mimeType = pickMimeType();
      recorder = mimeType ? new MediaRecorder(stream, { mimeType: mimeType })
                          : new MediaRecorder(stream);

      recorder.ondataavailable = function (event) {
        if (event.data && event.data.size > 0) { chunks.push(event.data); }
      };

      recorder.onstop = function () {
        clearTimers();
        stopLevelMeter();
        releaseStream();
        handleRecordingFinished();
      };

      recorder.start();

      var limit = Math.min(session.max_duration_seconds || 3, HARD_MAX_SECONDS);
      var startedAt = Date.now();

      button.classList.add("recording");
      button.textContent = "Stop";
      button.setAttribute("aria-label", "Stop recording");
      button.disabled = false;
      $("timer").classList.remove("hidden");
      $("meter").classList.remove("hidden");
      $("record-hint").textContent = "Recording… tap to stop early.";

      startLevelMeter(stream);

      tickTimer = setInterval(function () {
        var elapsed = (Date.now() - startedAt) / 1000;
        var remaining = Math.max(0, limit - elapsed);
        $("timer").textContent = remaining.toFixed(1) + "s";
      }, 80);

      stopTimer = setTimeout(function () {
        if (recorder && recorder.state === "recording") { recorder.stop(); }
      }, limit * 1000);

    }).catch(function (error) {
      button.disabled = false;
      var name = error && error.name ? error.name : "";
      if (name === "NotAllowedError" || name === "SecurityError") {
        setStatus("record-status",
          "Microphone access was blocked. Allow it in your browser settings, then tap Record again.",
          "error");
      } else if (name === "NotFoundError") {
        setStatus("record-status", "No microphone was found on this device.", "error");
      } else {
        setStatus("record-status", "Could not start recording. " + (error.message || ""), "error");
      }
    });
  }

  function stopPlayback() {
    if (playbackSource) {
      try { playbackSource.stop(); } catch (e) { /* already finished */ }
      try { playbackSource.disconnect(); } catch (e) { /* already gone */ }
      playbackSource = null;
    }
    if (previewAudio) {
      try { previewAudio.pause(); } catch (e) { /* not playing */ }
      previewAudio = null;
    }
    if (previewUrl) { URL.revokeObjectURL(previewUrl); previewUrl = null; }
  }

  // Playback is instrumented because it has failed twice for reasons that were
  // invisible on a phone. Every stage reports to #audio-trace so the failing
  // step is visible on screen instead of only in a console nobody can open.
  function trace(line) {
    if (window.console && window.console.log) { window.console.log("[crowdloop] " + line); }
    if (!DEBUG) { return; }
    var el = $("audio-trace");
    if (!el) { return; }
    el.textContent += (el.textContent ? "\n" : "") + line;
  }

  function clearTrace() {
    var el = $("audio-trace");
    if (el) { el.textContent = ""; }
  }

  function describeCtx(ctx) {
    if (!ctx) { return "no AudioContext"; }
    return "ctx state=" + ctx.state + " rate=" + ctx.sampleRate + "Hz";
  }

  // Same context and same output as playBack, but nothing is decoded. If this
  // is audible and the recording is not, the problem is the audio data. If
  // neither is audible, the problem is the context or the output route.
  function playTestTone() {
    clearTrace();
    setAudioSession("playback");
    var ctx = unlockAudio();
    trace("tone: " + describeCtx(ctx));
    trace("tone: " + describeSession());

    if (!ctx) {
      trace("tone: FAILED, no Web Audio on this browser");
      return;
    }

    try {
      var osc = ctx.createOscillator();
      var gain = ctx.createGain();
      osc.frequency.value = 440;
      gain.gain.value = 0.2;
      osc.connect(gain);
      gain.connect(ctx.destination);
      osc.start();
      osc.stop(ctx.currentTime + 0.6);
      trace("tone: started 440Hz for 0.6s");
      osc.onended = function () { trace("tone: finished, state=" + ctx.state); };
    } catch (error) {
      trace("tone: THREW " + (error.message || error));
    }
  }

  function playBack() {
    clearTrace();

    if (!recordedWav) {
      trace("play: nothing recorded yet");
      return;
    }
    trace("play: blob " + recordedWav.size + " bytes, type " + (recordedWav.type || "(none)"));

    stopPlayback();
    setAudioSession("playback");
    var ctx = unlockAudio();
    trace("play: " + describeCtx(ctx));
    trace("play: " + describeSession());

    if (!ctx) {
      trace("play: no Web Audio, using <audio> fallback");
      playBackFallback();
      return;
    }

    recordedWav.arrayBuffer().then(function (data) {
      trace("play: read " + data.byteLength + " bytes");
      return new Promise(function (resolve, reject) {
        var maybe = ctx.decodeAudioData(data, resolve, reject);
        if (maybe && typeof maybe.then === "function") {
          maybe.then(resolve).catch(reject);
        }
      });
    }).then(function (buffer) {
      trace("play: decoded " + buffer.duration.toFixed(2) + "s, " +
            buffer.numberOfChannels + "ch @ " + buffer.sampleRate + "Hz");

      var source = ctx.createBufferSource();
      source.buffer = buffer;
      source.connect(ctx.destination);
      source.onended = function () {
        playbackSource = null;
        trace("play: finished");
      };
      source.start(0);
      playbackSource = source;

      trace("play: started, ctx state=" + ctx.state);
      if (ctx.state !== "running") {
        trace("play: context is NOT running — no sound will come out");
      }
    }).catch(function (error) {
      trace("play: FAILED " + (error && error.message ? error.message : error));
      trace("play: trying <audio> fallback");
      if (window.console) { console.error(error); }
      playBackFallback();
    });
  }

  // Only reached if Web Audio is unavailable or the decode fails.
  function playBackFallback() {
    if (!recordedWav) { return; }
    if (previewUrl) { URL.revokeObjectURL(previewUrl); }
    previewUrl = URL.createObjectURL(recordedWav);
    previewAudio = new Audio(previewUrl);
    previewAudio.setAttribute("playsinline", "");
    previewAudio.playsInline = true;

    previewAudio.onerror = function () {
      trace("fallback: <audio> could not load the blob");
    };
    previewAudio.onplaying = function () {
      trace("fallback: <audio> is playing");
    };

    previewAudio.play().then(function () {
      trace("fallback: play() resolved");
    }).catch(function (error) {
      trace("fallback: play() rejected — " + (error && error.name ? error.name : error));
      setStatus("review-status",
        "Could not play it back here. You can still send it.", "error");
    });
  }

  function send() {
    if (!recordedWav || !session || sending) { return; }
    sending = true;

    stopPlayback();

    var sendButton = $("send-btn");
    sendButton.disabled = true;
    $("redo-btn").disabled = true;
    setStatus("review-status", "Sending\u2026");

    var submissionId = uuid();
    var bytes = recordedWav.size;
    var chosenLabel = $("label-input").value;

    // Audio first, then the row. A row that exists therefore always has audio
    // behind it; a failed send leaves at most an unreferenced file.
    uploadAudio(session.id, submissionId, recordedWav).then(function (path) {
      return createSubmission(submissionId, session.id, path,
                              recordedSeconds, bytes, chosenLabel);
    }).then(function () {
      sending = false;
      $("redo-btn").disabled = false;
      recordedWav = null;
      show("done");
    }).catch(function (error) {
      sending = false;
      sendButton.disabled = false;
      $("redo-btn").disabled = false;

      var message = String(error && error.message ? error.message : error);

      } else {

    if (!code) {
      setStatus(statusId, "Enter the code first.", "error");
      return;

    setStatus(statusId, "Checking…");

    lookupSession(code).then(function (found) {
      if (!found) {
        setStatus(statusId,
          "No open session with that code. Check the code, or the session may have closed.",
          "error");
        return;
      }
      enterSession(found);
    }).catch(function (error) {
      setStatus(statusId, describeError(error), "error");
      if (window.console) { console.error(error); }
    });
  }

Supabase

Free tier

  • 1 GB of audio storage. A three-second recording is about 290 KB, so that is roughly 3,400 sounds.
  • 500 MB database for the records that go with them.
  • 50,000 monthly active users. Your audience never signs in, so in practice this counts only you.
  • No card required.

A busy show might produce a hundred sounds. You will run out of patience for listening to them long before you run out of space.

One catch: a free project sleeps after 7 days of no activity and does not wake on its own, and can be closed for good after 90 days asleep. One click from the dashboard prevents both.

Netlify

Free tier

  • 100 GB of traffic a month. Your page is about 48 KB, so that is roughly two million opens.
  • One file, no build step. You drag a folder onto a web page and it is live.
  • Free https, which the microphone requires.
  • No card required.

Netlify is doing nothing clever here — it is a web server for a single file. Any host that serves https works identically, which is why you can skip it entirely if you already have a website.

Never use the service_role key

Step 4.4

  • On that same screen there is a key called service_role.
  • It bypasses every rule protecting your recordings.
  • Never put it in the app, the page, or anything you paste into an AI tool.
  • Nothing in this guide needs it.

The publishable key is the opposite and is meant to be public — it sits inside your web page where anyone can read it. On its own it lets someone do exactly what an audience member can do: add one pending recording to a session that is open right now. Nothing else.

The builder in step 5 and the iPad app both refuse a service_role key outright, so you have two nets under you here.

Already have your own website?

Skip step 5.1

  • Press Copy the code instead in the builder above.
  • Paste it into a file called index.html
  • Put it wherever you already host things — your own server, GitHub Pages, Cloudflare Pages, Vercel, anywhere.

Two rules only. It must be served over https, because browsers refuse microphone access otherwise. And it must be served exactly as given, with no build step that minifies, splits or transforms it.

Privacy policy

Effective 19 September 2026 · the CrowdLoop iOS app and the CrowdLoop recording page

The short version

  • CrowdLoop collects no personal information from audience members.
  • A sound, and an optional short name for it, is everything that leaves the phone.
  • It goes to the performer's own server and nowhere else.
  • No analytics, no advertising, no tracking, and no third-party code in either the app or the page.

Who holds what

This matters more here than in most apps, because every performer runs their own backend. Recordings never pass through the developer's servers, because there are no developer servers.

  • Mr. Brad's Music, who makes CrowdLoop, receives nothing. No recordings, no accounts, no usage data, no crash reports, no analytics.
  • The performer holds the recordings, in a Supabase project on their own account, under their own control.
  • Supabase stores and serves that data on the performer's behalf.

If you are a performer reading this: for your own audience's recordings, you are the one holding the data. This policy describes what the software does. What you then do at your events is yours to stand behind.

What the recording page collects

When an audience member sends a sound, these are submitted:

  • the audio recording
  • an optional label they typed, up to 40 characters
  • the length of the recording, its size and its format
  • the time it was sent

That is the complete list. No name, no email address, no phone number, no location, no contacts, no photos, no advertising identifier, no device fingerprint, no cookies, and no account of any kind. The page asks the browser for microphone permission at the moment of recording, and for no other permission at any time.

Network-level data. Like every request on the internet, an upload arrives at Supabase carrying the IP address it came from, and Supabase may record that in its own service logs. CrowdLoop does not read those logs, does not store IP addresses in its database, and never associates one with a recording.

What the app collects

From the performer only:

  • Email and password for the performer's own Supabase project. These are held by Supabase. The password is never stored on the device; the sign-in token is kept in the iOS Keychain.
  • Backend coordinates — project URL, publishable key, recording page address — kept in app settings on the device.

None of it is sent to the developer.

Children

CrowdLoop is used at family shows. A recording may well be made by a child, usually on a parent's phone, with a parent standing right there.

The recording page is built so that this collects nothing personal. There is no sign-in, no account, no contact field, no location, and no identifier of any kind. A voice and an optional label is all there is, and the performer can edit or delete the label. The app itself is a performer's tool and is not directed at children as users.

Performers: how you use recordings of children at your own events is your responsibility, not the software's. Say what you are doing, and treat consent the way you already do for photographs.

How recordings are used

  • Every submission arrives pending. Nothing plays automatically and nothing reaches a pad until the performer approves it by hand.
  • Approved sounds may be played during that performer's show.
  • Recordings are not sold, published, shared, or used for anything outside the show they were made for.

Keeping and deleting

Recordings stay in the performer's Supabase project until the performer removes them. Deleting a session in the app removes that session and every recording in it, from the server and from the device.

Audience members: a recording carries nothing that identifies you, which also means there is nothing to look you up by. If you want a sound removed, ask the performer — they can find it by when it arrived and what it sounds like.

Security

  • All traffic uses HTTPS.
  • The audio store is private. Sound comes back out only through a temporary signed link issued to the signed-in performer.
  • The key inside the public page can add one pending recording to a currently-open session and do nothing else. It cannot read, change, approve or delete anything — not even the recording it just made.
  • The performer's sign-in token is stored in the iOS Keychain.

  • Venmo, only if the performer switched the tip button on, and only if somebody taps it. That opens Venmo's own site, and anything that happens there is between the payer and Venmo. CrowdLoop sees none of it.

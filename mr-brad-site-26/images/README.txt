Put your photos and app screenshots in this folder.

Example file names you might use:
  hero.jpg
  show-1.jpg
  workshop.jpg
  gallery-1.jpg ... gallery-6.jpg
  piano-app.png

Then reference them in /js/content.js, for example:
  images: { heroHome: "images/hero.jpg" }
  gallery: [ { src: "images/gallery-1.jpg", label: "Library show" } ]

Recommended: JPG or PNG, roughly 1200px wide, under ~400 KB each, so the
site loads fast on phones.
